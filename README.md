# stock-tycoon-rankband-dist

**股市大亨 · 排行榜** 的公开分发仓库。

主仓库（**私有**，含源码与签名私钥）不对外；这里只放 App 自动更新所需的东西。

## 为什么单独开一个公开仓库

手机应用的自动更新必须能**匿名读取**清单与安装包，所以这个仓库必须公开。
而主仓库跟踪着 interconnect 的**签名私钥** —— 签名是手环与手机两端唯一的身份凭证，
私钥一旦公开，任何人都能签出同包名、同签名的伪造包；配合"强制更新"就是主动向用户推攻击者的包。
所以主仓库保持私有，只有产物进这里。详见主仓库 `docs/12-update-and-push.md`。

## 内容

| 文件 | 作用 |
|---|---|
| `version.json` | 更新清单。App 读取后与自身 `versionCode` 比较：低于 `minSupportedVersionCode` 强制更新，否则提示可选更新 |
| `notices.json` | 推送内容（游戏活动 / 版本公告）。App 联网取回，落盘缓存后可离线查看 |

安装包与手环端 RPK 作为 **Release 附件** 提供（见 Releases 页）。

## ⚠️ 手环端需要手动安装

手环端 RPK **无法自动更新**：官方 SDK 不能安装 rpk（只能拉起已装的），
手环本身也不能联网。请用 AstroBox / 表盘自定义工具等按包名卸载旧版后安装新版。

- 包名：`com.stocktycoon.rankband`
- 手环端与手机端**必须同时升级**（两端版本号与签名要一致）
